# Procedra research package

This folder contains the public-safe research package for Procedra as a controlled local-demo prototype and source-supported software artifact for human-in-the-loop industrial AI.

Included public artifacts:

- `procedra_ssrn_working_paper.md` - working paper source.
- `procedra_ssrn_working_paper_pdf_ready.md` - PDF-oriented Markdown source used by the builder.
- `procedra_ssrn_working_paper.pdf` - generated working paper PDF.
- `procedra_ssrn_submission_package.md` - SSRN copy-paste metadata.

The paper and metadata intentionally avoid unsupported claims about production deployment, certified compliance, customer validation, paid pilots, revenue, measured productivity gains, or replacement of qualified expert review.

Local audit notes, claim-review notes, raw logs, runtime artifacts, generated databases, uploads, private handoff materials, and customer-sensitive materials are not part of this public research package.
