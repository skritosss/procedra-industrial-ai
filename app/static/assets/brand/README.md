# Procedra production identity assets

The deterministic wordmark is redrawn from the selected `Constructed Wordmark`
direction under `outputs/logos/procedra-2026-06-21/`.

## Files

- `procedra-wordmark.svg` / `.png`: primary horizontal graphite/teal wordmark.
- `procedra-wordmark-monochrome.svg` / `.png`: one-color document variant.
- `procedra-wordmark-reversed.svg` / `.png`: reversed dark-surface variant.
- `procedra-favicon.svg`, `procedra-favicon-32.png`, and
  `procedra-apple-touch-icon.png`: small-size E-derived brand mark.

All SVG lettering is outlined as paths. It does not depend on locally installed
fonts, external URLs, inline application SVG, JavaScript, or CSS.

Oxanium was used as the licensed geometric construction base and converted to
outlines. The retained source font and `OFL-Oxanium.txt` are included for
provenance and future authorized redraws. The teal intervention in the E is a
Procedra-specific deterministic modification.

## Tokens

- Graphite: `#17212B`
- Industrial teal: `#0F766E`
- Reversed accent: `#42C5B8`
- White: `#FFFFFF`

## Boundary

These files are production-shaped application assets, but they do not imply
legal trademark clearance. Formal similarity and trademark review is still
required before public launch.
